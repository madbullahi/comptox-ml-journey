# Resources

## Courses (free or free to audit)
- [Kaggle Learn](https://www.kaggle.com/learn) — Python, pandas, intro ML, data visualisation
- [Machine Learning Specialization — Andrew Ng](https://www.coursera.org/specializations/machine-learning-introduction) (audit free)
- [Practical Deep Learning for Coders — fast.ai](https://course.fast.ai/)
- [Neural Networks: Zero to Hero — Andrej Karpathy](https://karpathy.ai/zero-to-hero.html)
- [3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)
- [TeachOpenCADD](https://projects.volkamerlab.org/teachopencadd/) — cheminformatics tutorials in Jupyter

## Cheminformatics & toxicology tools
- [RDKit documentation](https://www.rdkit.org/docs/)
- [Chemprop](https://github.com/chemprop/chemprop) — graph neural networks for molecular property prediction
- [DeepChem / MoleculeNet](https://deepchem.io/)
- [Practical Cheminformatics blog — Pat Walters](https://practicalcheminformatics.blogspot.com/)
- OECD QSAR Toolbox and OECD guidance on QSAR validation
- [AOP-Wiki](https://aopwiki.org/)

## Datasets
- [EPA CompTox Chemicals Dashboard](https://comptox.epa.gov/dashboard/) — chemicals, ToxCast, PFAS lists
- Tox21 (via MoleculeNet / DeepChem)
- [PubChem](https://pubchem.ncbi.nlm.nih.gov/) and [ChEMBL](https://www.ebi.ac.uk/chembl/)
- [CARD — Comprehensive Antibiotic Resistance Database](https://card.mcmaster.ca/)
- [NCBI Pathogen Detection](https://www.ncbi.nlm.nih.gov/pathogens/)
- [BV-BRC](https://www.bv-brc.org/) — AMR phenotype data
